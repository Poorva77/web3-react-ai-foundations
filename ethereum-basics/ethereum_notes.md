# Ethereum Basics

## What is Ethereum?

Ethereum is a decentralized blockchain platform that supports smart contracts and decentralized applications (dApps).

---

## Ether (ETH)

ETH is the native cryptocurrency of Ethereum used for:
- Transactions
- Gas fees
- Smart contract execution

---

## Smart Contracts

Smart contracts are self-executing programs stored on blockchain.

Features:
- Automatic execution
- Immutable
- Transparent
- Secure

---

## Ethereum Virtual Machine (EVM)

EVM is the runtime environment that executes smart contracts on Ethereum.

---

## Gas Fees

Gas fees are transaction costs paid to execute operations on Ethereum.

Gas depends on:
- Complexity
- Network traffic
- Storage usage

---

## Wallets

Wallets are used to store cryptocurrency and interact with blockchain.

Examples:
- MetaMask
- Trust Wallet
- Coinbase Wallet

---

## Public and Private Keys

### Public Key
Acts like wallet address.

### Private Key
Secret key used to authorize transactions.

Never share private keys.
