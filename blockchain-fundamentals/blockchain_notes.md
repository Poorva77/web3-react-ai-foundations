# Blockchain Fundamentals

## What is Blockchain?

Blockchain is a decentralized digital ledger that stores data in blocks connected using cryptography.

Each block contains:
- Transaction Data
- Previous Block Hash
- Current Block Hash
- Timestamp

---

## Key Features of Blockchain

### 1. Decentralization
Data is not controlled by a single authority.

### 2. Transparency
Transactions are visible to all participants in the network.

### 3. Immutability
Data once added cannot be easily modified.

### 4. Security
Cryptographic hashing secures the blockchain.

---

## How Blockchain Works

1. User requests a transaction
2. Transaction is broadcasted to network
3. Nodes validate transaction
4. Transaction added to a block
5. Block added to blockchain

---

## Types of Blockchain

### Public Blockchain
Open for everyone.
Example:
- Bitcoin
- Ethereum

### Private Blockchain
Controlled by a single organization.

### Consortium Blockchain
Managed by multiple organizations.

---

## Consensus Mechanisms

Consensus mechanisms help nodes agree on valid transactions.

### Proof of Work (PoW)
Uses computational power to validate blocks.

### Proof of Stake (PoS)
Validators are selected based on staked cryptocurrency.

---

## Advantages of Blockchain

- Transparency
- Security
- Reduced fraud
- Faster transactions
- Decentralized control
